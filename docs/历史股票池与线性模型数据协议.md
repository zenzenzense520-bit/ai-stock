# 历史股票池与线性模型数据协议

## 股票池输入

使用 `--universe-file` 传入 CSV，列名为 `code,valid_from,valid_to,published_at,source`。每行定义某只股票在闭区间 `[valid_from, valid_to]` 内属于候选集合，`published_at` 是该记录公开可知的日期，不能晚于 `valid_from`。同一股票的时间区间不能重叠。文件路径只用于本地输入，不会自动上传。

```csv
code,valid_from,valid_to,published_at,source
600001,2024-01-01,2024-06-30,2023-12-15,示例来源
```

上例仅说明格式，不代表真实成分数据。实际使用时，应保存指数或股票池历史成分的官方公告链接、公布时间、成分调整生效时间和退市股票，并核对行情数据是否覆盖这些股票。缺少这些证据时，不能声称回测的股票池无前视或幸存者偏差。

## 模型比较

`factor_rank` 与 `ridge_rank` 使用同一个滚动训练/测试划分、同一候选池、调仓周期、Top N、交易成本和风控参数。历史成员模式仅运行这两种排名策略。岭回归使用四个现有价格量能因子，标准化均值、标准差和模型系数只由训练窗数据计算，正则化强度固定为 1。训练窗最后 `forward_window` 个交易日的未来收益标签会被丢弃。

结果位于 `output/report.csv`，每窗权重/系数分别位于 `output/factor_rank_weights.csv` 和 `output/ridge_rank_weights.csv`。同一报告中的传统策略覆盖完整数据段，而两种排名策略只覆盖训练窗之后的样本外区间；比较策略优劣时只能使用共同区间。

## 当前限制

仓库提供的 `data/sample_pool.csv` 是 4 只银行股的固定示例，不是历史指数成分。历史股票池模式要求所有输入股票在任一有效成员存在的基准交易日都有行情；缺少代码或交易日会停止回测。停牌也可能触发该保守检查。当前回测器尚不能正确处理退市/摘牌后的组合估值。组合回测把每只股票视为独立资金袖套后平均净值，尚不等同于统一现金账户的每日组合再平衡。公开前复权行情和近似涨跌停规则也可能与真实交易不同。报告仅用于代码学习和方法验证。
